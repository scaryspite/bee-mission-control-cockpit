# Bee Mission Control Cockpit

Bee Mission Control Cockpit is the Phase 2 experience/personality layer for Bee Mission Control.

It is not the Bee Brain Navigator.
It is not a migration.
It is not a generic dashboard.

## Role

Bee Mission Control is the parent operating system / command center.

This cockpit provides the visible command deck for:
- daily workflow
- system status
- project navigation
- source-aware context access
- child app launch points
- assistant state/personality

## System Map

- Bee Mission Control = parent operating system / command center
- Bee Brain = knowledge/context/source authority layer
- Bee Brain Navigator = local read-only retrieval prototype
- iCloud = storage layer
- Game Hub = separate active child app

## Experience Direction

Alien / Nostromo:
- lived-in ship computer
- industrial, dim, practical, slightly haunted
- old monitors, warning lights, utility labels, command panels

Red Dwarf:
- absurd survival humor
- systems barely cooperating but still operational
- dry ship-computer messages
- funny failure states that still explain the real issue

Elder internet:
- Xanga/MySpace/AIM/custom homepage energy
- personal corner of the internet
- buttons, badges, tiny widgets, status panels
- expressive but readable

Classic anime / Toonami:
- space transmission energy
- late-night command deck
- dramatic mission labels
- bumper-style transitions

## Assistant Character

A tiny 8-bit ship gremlin / digital stowaway / assistant sprite.

The assistant is:
- competent
- dramatic
- mildly exhausted
- loyal
- a little rude

The assistant is not:
- Clippy
- a waifu
- a corporate helper
- the authority

## Assistant States

- idle: tiny pixel assistant with coffee / blinking in the corner
- searching: rummaging through folders
- thinking: CRT loading bar, floppy disk, tape reel, or signal scan
- success: tiny victory pose
- error: funny failure message plus the real error
- serious mode: jokes off for clinical, compliance, safety, money, scheduling, and source-authority contexts

## Core Line

“The future was supposed to be magical. It wasn’t. So we kept the magic ourselves.”

## Usability Rules

- Source visibility stays clear.
- Project status stays clear.
- Navigation stays clear.
- Daily workflow stays clear.
- Decoration must not overpower function.
- Bee Brain/source authority remains the truth layer.
