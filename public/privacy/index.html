Bee Mission Control Privacy Policy

Last updated: September 15, 2026

About Bee Mission Control

Bee Mission Control is a personal productivity and organization application that helps its authorized user review schedules, organize tasks, retrieve relevant work information, manage files, and coordinate personal workflows.

Google account access

Bee Mission Control accesses Google account data only after the user explicitly authorizes access through Google OAuth.

Google Calendar data

Bee Mission Control may access Google Calendar information including event titles, dates, start and end times, and other event information available through the Calendar permissions authorized by the user.

Calendar data is used to display schedules, identify upcoming commitments, prepare daily planning information, detect scheduling conflicts, and help organize time-based tasks.

Gmail data

Bee Mission Control may access Gmail information when the user requests email-related functionality such as locating relevant work messages, identifying scheduling information, or retrieving information needed for a requested workflow.

Depending on the permissions authorized by the user, this may include sender, recipient, subject, date, labels, and message content needed to complete the requested task.

How Google user data is used

Google user data is used only to provide user-facing features requested by the authorized user. Bee Mission Control does not use Google user data for advertising, ad targeting, marketing profiles, or unrelated purposes.

Data storage and retention

Bee Mission Control is designed to avoid unnecessary copies of Google user data. Where practical, source information remains in the originating Google service and is retrieved only when needed for a requested feature.

Some derived information or application context may be stored within the user's Bee Mission Control environment when necessary to provide application functionality.

Data sharing

Bee Mission Control does not sell Google user data and does not share it with advertisers or data brokers for advertising, profiling, or marketing.

Human access

Google user data is not routinely reviewed by humans. Human access may occur only when authorized by the user, when necessary to investigate a security or technical issue, or when required by law.

Security

Bee Mission Control uses reasonable technical safeguards intended to protect account information and Google user data from unauthorized access, disclosure, alteration, or loss.

Revoking access

Users can revoke Bee Mission Control's Google Account access at any time through their Google Account security and permissions settings.

Data deletion

Users may request deletion of information stored by Bee Mission Control by contacting packets@beemissioncontrol.com.

Google API Services User Data Policy

Bee Mission Control's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Privacy questions or deletion requests: packets@beemissioncontrol.com
